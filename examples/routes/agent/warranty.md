# Company agent route

A conversation for a task the API should not close alone. The announcement uses a warranty claim as the example. This transcript is a reading model of that route, in the same visit shape as the address change.

NiCE's public description of the protocol adds two details used here. A person can join the conversation with the context already in hand. Each reply says whether an agent or a person is speaking.

`session_id` is `ses_7f3a` only to show the discipline. A warranty claim would be its own visit. The address-change visit would reach this door if the parcel had already left the depot.

## Transcript

**Personal agent** · session `ses_7f3a` · customer granted write access

Order NL-20418 arrived with a cracked lid. The customer wants a replacement, shipped to the address on the order.

**Northline agent**

The order qualifies for a replacement. The lid is a warehouse item. I can ship it today.

**Person at Northline** · joined the same conversation

Hold the shipment. That lid is in a batch we are checking. I will send a different batch, or a refund of the lid, by tomorrow at 16:00.

**Northline agent**

Recorded. The customer will hear which of the two it is by tomorrow at 16:00. Speaker for that update: a person at Northline.

The personal agent keeps the session. The customer does not have to retell the order, the damage, or the address.
